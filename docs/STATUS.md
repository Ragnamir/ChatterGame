# Статус этапов

Хронология прохождения этапов по протоколу `PLAN §1`. Запись добавляется по сдаче этапа,
удаляется только если этап отменён решением владельца.

Формат записи:

```
## <STAGE> — <название>
Дата: YYYY-MM-DD
Гейт: GREEN | RED | N/A
Сделано:
Отклонения от плана:
Новые вопросы:
Решения: (ссылки на D-xxx, если этап породил решение)
```

---

## Текущее состояние

Ни один этап не начат. Документация заморожена на уровне `REQUIREMENTS`, `DECISIONS`, `PLAN`.

Открытые вопросы владельца продукта перед `E01` (`PLAN §6`):

1. Подтвердить или заменить `D-090` — frontend-стек. Нужно до `F01`, не блокирует бэк.
2. Подтвердить, что каркас миграции `E01` включает все таблицы сразу, включая неиспользуемые.
3. Указать целевую среду продакшена (один инстанс, контейнер, VM) — влияет на формат логов
   и способ развёртывания в `E01`, на домен не влияет.
