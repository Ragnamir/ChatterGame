# Статус этапов

Хронология прохождения этапов по протоколу `PLAN §1`. Запись добавляется по сдаче этапа,
удаляется только если этап отменён решением владельца.

Формат записи:

```
## <STAGE> — <название>
Дата: YYYY-MM-DD
Гейт: GREEN | RED | N/A
Сделано:
Отклонения от плана:
Новые вопросы:
Решения: (ссылки на D-xxx, если этап породил решение)
```
